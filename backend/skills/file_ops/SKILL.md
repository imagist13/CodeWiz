## 使用场景

- 读取仓库中的现有文件内容
- 在仓库中搜索包含特定关键词的文件
- 写入或更新代码文件
- 查看文件目录结构

## 工具说明

此工具封装了对 Conduit 仓库的文件操作，包括：

1. **conduit_read_context** — 读取文件内容，支持行高亮
2. **conduit_search_files** — 搜索包含关键词的文件
3. **conduit_write_code** — 写入代码文件（原子写入）
4. **conduit_search_keyword** — 按正则搜索代码行

## 安全约束

- 所有路径必须在 Conduit 仓库目录下
- 不允许访问仓库外的路径
- 写入前自动备份（保留 3 份历史）
