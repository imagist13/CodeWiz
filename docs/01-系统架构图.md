## 4. Orchestrator / Agent Loop

```
┌─────────────────────────────────────────────────────────────────┐
│                    Agent Loop (agent-loop.ts)                    │
│                                                                  │
│   start ──► while (!done && steps < maxSteps)                   │
│              │                                                   │
│              ├──► Sync MCP Servers (latest tools)               │
│              │                                                   │
│              ├──► Build Tool Set (allowedTools / disallowedTools)│
│              │                                                   │
│              ├──► streamText() ──► Model API                    │
│              │        │                                         │
│              │        ├── text_delta ──► SSE 'text'             │
│              │        ├── thinking_delta ──► SSE 'thinking'      │
│              │        ├── tool_use ──► SSE 'tool_use'           │
│              │        │       │                                  │
│              │        │       ▼                                  │
│              │        │   Tool Executor                         │
│              │        │   ├─ Read / Write / Edit / Bash        │
│              │        │   ├─ Glob / Grep                        │
│              │        │   ├─ Skill / Agent (sub-agent)          │
│              │        │   └─ tool_result ──► SSE 'tool_result'  │
│              │        │                                          │
│              │        ├── error ──► SSE 'error'                  │
│              │        └── done ──► SSE 'result'                  │
│              │                                                   │
│              ├──► Check: Doomer Loop? (3x same tool → break)    │
│              │                                                   │
│              ├──► Emit: rewind_point (before each user msg)      │
│              │                                                   │
│              ├──► Check: needsCompression? → auto /compact       │
│              │                                                   │
│              └──► steps++                                       │
│                                                                  │
│   end ──► Emit SSE 'done', token usage, cost                    │
└─────────────────────────────────────────────────────────────────┘
```

## 5. Sandbox-Repo (File Checkpoint / Rewind)

```
┌─────────────────────────────────────────────────────────────────┐
│              File Checkpoint System (file-checkpoint.ts)        │
│                                                                  │
│   Rewind Point 触发时机:                                         │
│   - 每条用户消息前创建 checkpoint                                 │
│   - 显式 /rewind 命令                                            │
│                                                                  │
│   ┌─────────────────────────────────────────────────────────┐   │
│   │  createCheckpoint(sessionId, messageId, cwd)            │   │
│   │  1. 遍历 modifiedFiles (追踪的已修改文件)                  │   │
│   │  2. 读取当前文件内容                                      │   │
│   │  3. 存入 in-memory Map<filePath, FileSnapshot>           │   │
│   │  4. FIFO: 超过20个则淘汰最旧的 checkpoint                 │   │
│   │  5. NEVER 使用 git checkout HEAD                        │   │
│   │     (保护会话前未提交的本地变更)                          │   │
│   └─────────────────────────────────────────────────────────┘   │
│                              │                                   │
│                              ▼                                   │
│   ┌─────────────────────────────────────────────────────────┐   │
│   │  restoreCheckpoint(sessionId, messageId, cwd)          │   │
│   │  1. 查找目标 messageId 对应的 checkpoint                 │   │
│   │  2. 遍历 snapshots Map                                   │   │
│   │  3. 逐文件恢复到快照内容                                  │   │
│   │  4. 返回被恢复的文件列表                                  │   │
│   └─────────────────────────────────────────────────────────┘   │
│                                                                  │
│   ┌─────────────────────────────────────────────────────────┐   │
│   │  Rewind API (POST /api/chat/rewind)                    │   │
│   │                                                          │   │
│   │  Dual Path:                                              │   │
│   │  ┌─────────────────┐   ┌─────────────────────────────┐ │   │
│   │  │ SDK Path:       │   │ Native Path:                │ │   │
│   │  │  conversation.   │   │  1. 截断 SQLite messages    │ │   │
│   │  │  rewindFiles()   │   │  2. restoreCheckpoint()     │ │   │
│   │  └─────────────────┘   │  3. 重新组装上下文            │ │   │
│   │                        └─────────────────────────────┘ │   │
│   └─────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘
```
