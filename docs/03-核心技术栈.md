## 3. 数据库

### SQLite

| 项目 | 详情 |
|------|------|
| **引擎** | `better-sqlite3`（Node.js 原生绑定，高性能同步 API） |
| **位置** | `~/.codepilot/codepilot.db` |
| **迁移** | 自动检测 + 文件锁并发保护 |

| `mcp_servers` | MCP 服务器配置 |

| `custom_cli_tools` | 自定义 CLI 工具注册 |

## 4. 中间件

### MCP (Model Context Protocol)

| 组件 | 技术 |
|------|------|
| **MCP 运行时** | `@modelcontextprotocol/sdk` |
| **加载器** | 自研 `mcp-loader.ts`（多来源配置合并） |

**内置 CodePilot MCP 服务器（动态加载）：**

| MCP Server | 触发关键词 | 用途 |
|------------|-----------|------|
| `codepilot-memory` | 无条件 | 记忆搜索与存储 |
| `codepilot-notify` | 无条件 | 通知推送 |
| `codepilot-widget` | 可视化/图表/diagram | Widget 指南 |
| `codepilot-media` | 生成图片/import media | 图片导入与生成 |
| `codepilot-cli-tools` | install/uninstall 命令 | CLI 工具管理 |
| `codepilot-dashboard` | Dashboard 操作 | Widget 仪表盘管理 |

**MCP 配置来源（合并优先级）：**

1. `~/.claude.json`（用户级 MCP 配置）
2. `~/.claude/settings.json`（Claude Code 设置）
3. `<cwd>/.mcp.json`（项目级 MCP 配置）
4. 代码中的 `mcpServerOverrides`（运行时覆盖）

### 消息队列与定时任务

| 组件 | 技术 |
|------|------|
| **任务调度器** | 自研 `task-scheduler.ts`（Cron + Interval 两种模式） |
| **持久化** | SQLite `scheduled_tasks` 表 |
| **触发器** | 内置定时轮询（不依赖外部队列系统） |

### 缓存层

| 组件 | 技术 |
|------|------|
| **Skill 缓存** | Per-`cwd` 内存缓存 + 手动失效 |
| **Provider 缓存** | `provider-catalog.ts` 静态数据 |
| **会话缓存** | `conversation-registry.ts`（`globalThis` 持久化） |

### 认证与授权

| 组件 | 技术 |
|------|------|
| **会话锁** | 文件锁 + 随机 lockId（防止并发冲突） |
| **权限模型** | `permission-registry.ts`（allow/deny + 审批队列） |
| **权限配置** | `permission_profile`（default / full_access） |

## 5. 部署环境

### 桌面客户端部署

| 环境 | 打包格式 | 架构 |
|------|----------|------|
| **macOS** | DMG, ZIP | x64, arm64 (Apple Silicon) |
| **Windows** | NSIS Installer (.exe) | x64, arm64 |
| **Linux** | AppImage, DEB, RPM | x64 |

**打包配置：** `electron-builder.yml`

```yaml
appId: com.codepilot.desktop
productName: CodeWiz
directories:
  output: release/${arch}
files:
  - .next/standalone/**
  - .next/static/**
  extraMetadata:
    main: packages/main/dist/index.js
asar: true
npmRebuild: true
```

### 服务端部署

| 环境 | 方式 |
|------|------|
| **本地开发** | `next dev`（热重载） |
| **生产构建** | `next build` → `next start`（Standalone 模式） |
| **Electron 内嵌** | `.next/standalone` 打包到 Electron 应用 |

**Next.js 配置：**

```typescript
// next.config.ts
{
  output: 'standalone',       // 独立可部署包
  serverExternalPackages: [
    'better-sqlite3',        // 原生模块
    'discord.js',            // 大型依赖
    '@discordjs/ws',
    'zlib-sync',
    '@anthropic-ai/claude-agent-sdk',
    'node-pty',
  ],
  outputFileTracingExcludes: [
    '**/*.md',               // 排除文档
    'apps/**',               // 排除文档站点
    'docs/**',               // 排除文档
    '.codepilot/**',
  ],
}
```

### 数据目录

| 环境变量 | 用途 | 默认值 |
|----------|------|--------|
| `CLAUDE_GUI_DATA_DIR` | 数据库和配置文件目录 | `~/.codepilot/` |

## 6. 云资源

### 自托管 vs 云端

CodeWiz 采用**本地优先（Local-First）**架构，不依赖任何云服务：

- **数据库**：本地 SQLite（`~/.codepilot/`）
- **AI 模型**：通过 API 调用第三方服务商
- **文件存储**：本地文件系统
- **用户认证**：无需（单人本地应用）

### 第三方 API 依赖

| 服务 | 用途 | 必需性 |
|------|------|--------|
| **Anthropic** | Claude 系列模型 | 可选 |
| **OpenAI** | GPT 系列模型 | 可选 |
| **OpenRouter** | 模型聚合（支持 100+ 模型） | 可选 |
| **AWS Bedrock** | Claude via AWS | 可选 |
| **Google Vertex AI** | Claude via GCP | 可选 |
| **GLM / Kimi / DeepSeek** | 国内模型 | 可选 |
| **Telegram Bot API** | 远程控制 | 可选 |
| **Discord Webhook API** | 远程控制 | 可选 |
| **飞书 Lark API** | 远程控制 | 可选 |
| **QQ Guild Bot API** | 远程控制 | 可选 |
| **微信企业号 API** | 远程控制 | 可选 |

### 无外部依赖项

| 类别 | 说明 |
|------|------|
| **无数据库云服务** | 全部使用本地 SQLite |
| **无 Redis / Memcached** | 缓存均在内存中，进程重启后重新加载 |
| **无消息队列** | 定时任务使用内置轮询调度器 |
| **无 CDN** | 静态资源随 Electron 包分发 |
| **无 Serverless** | Next.js Standalone 部署在自有服务器 |
