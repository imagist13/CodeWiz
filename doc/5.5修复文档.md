## Bug 1：类型字段名不一致（`repo-sidebar.tsx`）

[repo-sidebar.tsx:L33-L37](file:///d:/桌面/项目/项目/CodeWiz/frontend/components/assistant-ui/repo-sidebar.tsx#L33-L37) 定义了**同名但字段不同的本地类型**，与 [repo-types.ts:L17-L20](file:///d:/桌面/项目/项目/CodeWiz/frontend/lib/repo-types.ts#L17-L20) 冲突：

| 文件                         | 字段名                                               |
| -------------------------- | ------------------------------------------------- |
| `lib/repo-types.ts`（规范类型）  | `created_at`, `updated_at` (snake\_case，匹配 Go 后端) |
| `repo-sidebar.tsx`（本地重复定义） | `createdAt`, `updatedAt` (camelCase — **错误**)     |

```
repo-types.ts:          RepoConversation { created_at, updated_at }  ← 正确
repo-sidebar.tsx:       RepoConversation { createdAt, updatedAt }    ← 错误 ❌
```

**后果**：如果侧边栏未来任何代码访问 `conversation.createdAt` 会拿到 `undefined`。

## Bug 2：预览区 & 终端区 URL 混淆（`repo-workspace-shell.tsx`）

[repo-workspace-shell.tsx:L170-L177](file:///d:/桌面/项目/项目/CodeWiz/frontend/app/\[repoId]/repo-workspace-shell.tsx#L170-L177)：

```typescript
// sandbox-status API 返回的字段映射：
results[repo.id] = {
  previewUrl: data.proxy_url,           // = /api/sandbox-preview/:id  ✅
  devCommandTerminalUrl: data.preview_url,  // = http://localhost:31001  ❌ 浏览器里不能直接用!
};
```

**AI Service 的** **`/api/sandbox/status`** **返回的** **`preview_url`** **是原始** **`http://localhost:31001`**，这不是浏览器能直接访问的 URL（跨域 + 可能 HTTPS→HTTP 被拦截）。

然后在 [repo-workspace-shell.tsx:L694](file:///d:/桌面/项目/项目/CodeWiz/frontend/app/\[repoId]/repo-workspace-shell.tsx#L694)：

```typescript
const mainFrameSrc = proxyRoot ?? metadata!.previewUrl;  // 顶部预览 iframe
```

`mainFrameSrc` 用的是 `proxyRoot`（`/api/sandbox-preview/:id`）→ 这是**正确的**，走了 Next.js 同源代理。

但底部终端区 [repo-workspace-shell.tsx:L645-L660](file:///d:/桌面/项目/项目/CodeWiz/frontend/app/\[repoId]/repo-workspace-shell.tsx#L645-L660) 的 tab URL 也是 `proxyRoot`：

```typescript
const allTabs = [
  {
    id: "dev-server",
    label: "Dev Server",
    url: proxyRoot ?? metadata!.devCommandTerminalUrl,  // 终端也指向预览代理 ❌
    ...
  },
];
```

**底部"终端"tab 和顶部"预览"iframe 指向的是同一个 URL**（都是静态文件服务器代理）。这意味着：

- 点击 `+` 新建终端 → 还是同一个预览页面
- 没有一个独立的终端来显示 `npm run dev` 的编译输出

***
